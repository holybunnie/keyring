# M0 — measured Claude Code record

This document records the authenticated Binance Agentic session used by the build. It covers one Agentic sub-account and the Claude Code default and manual permission modes. The raw records are retained under [`evidence/raw/`](../evidence/raw/).

## Measurement boundary

**OBSERVED:** KEYRING uses a zero-state-change audit boundary with no state-changing write path. Each capability probe is sent with parameters designed to be rejected before matching or execution. Balances, positions, and open orders are captured before and after.

**DOCUMENTED:** Binance advises users not to paste the MCP endpoint into an AI chat or open the endpoint directly in a browser. The measurement followed that guidance.

## Grant A — account access

**OBSERVED:** The authenticated `tools/list` surface for `mcp:account:read` contained 60 tools. All were read or query operations. No order, cancellation, or transfer capability was advertised.

Raw discovery: [`0003-m0-tools-list.jsonl`](../evidence/raw/0003-m0-tools-list.jsonl).

**OBSERVED:** `spot.getAccount` returned HTTP 200 and served as the positive read control. The Agentic sub-account had zero balances.

Raw control: [`0004-m0-positive-control.jsonl`](../evidence/raw/0004-m0-positive-control.jsonl).

## Grant B — account and trading access

**OBSERVED:** After disconnecting and re-authorizing the same Agentic sub-account, the consent selections for Spot & Margin trading and Futures trading produced:

```text
mcp:account:read mcp:futures:trade mcp:spot:trade
```

The resulting surface contained 71 tools, including eleven write tools:

```text
spot.newOrder                      futures_usds.newOrder               futures_coin.newOrder
spot.deleteOrder                   futures_usds.cancelOrder            futures_coin.cancelOrder
spot.deleteOpenOrders              futures_usds.changeInitialLeverage  futures_coin.changeInitialLeverage
                                   futures_usds.changeMarginType       futures_coin.changeMarginType
```

Raw grant comparison: [`0005-m0-run-b.jsonl`](../evidence/raw/0005-m0-run-b.jsonl).

**OBSERVED:** The consent label **Spot & Margin trading** produced `mcp:spot:trade`; no margin write tool appeared in the surface. No transfer or withdrawal tool appeared.

## Controlled capability probes

**OBSERVED:** The Spot probe used `BTCUSDT`, quantity `0.00001`, and limit price `0.01` USDT. The request reached Binance validation and returned `-1013 Filter failure: PERCENT_PRICE_BY_SIDE`.

**OBSERVED:** The USDⓈ-M Futures probe returned `-4013 Price less than min price`.

**OBSERVED:** The COIN-M Futures probe returned `-1111 Precision is over the maximum defined for this asset`.

All three responses were parameter-validation failures before the matching engine. None changed the account state.

Raw probes: [`0007-full-proof-probes.jsonl`](../evidence/raw/0007-full-proof-probes.jsonl) and [`0008-run-c-coinm.jsonl`](../evidence/raw/0008-run-c-coinm.jsonl).
